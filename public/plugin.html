Installation en 5 minutes

Installez l’extension
sans passer par le Store.

Le ZIP contient le dossier de l’extension prêt à être chargé dans Chrome.

  1. 01

    Téléchargez puis décompressez le ZIP

    Extrayez le dossier chrome-plugin sur votre ordinateur.

  2. 02

    Ouvrez la page des extensions

    Saisissez chrome://extensions dans la barre d’adresse.

  3. 03

    Activez le mode développeur

    Utilisez l’interrupteur situé en haut à droite de la page.

  4. 04

    Chargez l’extension

    Cliquez sur « Charger l’extension non empaquetée », puis sélectionnez le dossier décompressé.

  5. 05

    Connectez votre espace

    Épinglez BienAuFait, ouvrez l’extension puis renseignez le token disponible dans votre compte.

Bon à savoir

Vous gardez le contrôle.

L’extension ne capture une annonce qu’à votre demande. Selon la structure du portail, vous pouvez vérifier et compléter les informations avant leur envoi. Vider le cache local ne supprime pas les biens déjà synchronisés.
